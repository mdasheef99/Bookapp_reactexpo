# Library typography

Static EB Garamond Medium/SemiBold and Manrope Regular/Bold reproduce the confirmed Stitch shelf typography through the existing expo-font dependency. Sources: `@expo-google-fonts/eb-garamond` 0.4.3 and `@expo-google-fonts/manrope` 0.4.2, downloaded from registry.npmjs.org without installing packages. Font licenses are retained in EBGaramond-OFL.txt and Manrope-OFL.txt. Book cloth is an original procedural SVG pattern in assets/images/decorative/book-cloth.svg.
